# OmniRift v0.1.145 — Pocket + Setup de Agentes

Esta versão torna o OmniRift mais simples para quem está começando sem retirar
as ferramentas avançadas de quem já usa o produto.

## OmniRift Pocket

- Instalações novas abrem no modo Pocket: projeto, equipe, canvas e execução em
  primeiro plano.
- Usuários existentes continuam no modo Completo depois da atualização, sem
  mudança inesperada no fluxo de trabalho.
- A troca entre **Pocket** e **Completa** fica em Configurações › Geral e é
  persistida localmente.
- Os dois modos usam os mesmos projetos, floors, agentes e banco. Alternar o
  modo não migra nem apaga dados.
- Sidebar Pocket com quatro etapas claras: projeto, agentes rápidos, paralelos
  e ferramentas essenciais.
- Acesso direto a Montar equipe, Central de API, Kanban, Histórico, Git,
  Configurações, Ajuda e Novidades.
- Toolbar reduzida a Montar equipe, Terminal, Agente, Nota e Árvore de arquivos.
- Paleta de comandos reduzida às ações essenciais, mantendo a navegação entre
  projetos e paralelos.
- Overlays avançados de importação de grafo, Conductor e métricas de recursos
  ficam ocultos no Pocket.
- O intro visual, o scan de custo e o polling do OmniFS não rodam no Pocket,
  reduzindo trabalho de fundo.
- O build de produção 0.1.145 nasce com edição Pocket para instalações novas.

## Setup completo de agentes

- O Arquiteto de Pipeline foi dividido em **Estrutura e fluxo** e
  **Setup dos agentes**.
- Cada papel do time pode escolher runtime, provider, modelo e credencial antes
  de ser montado no canvas.
- Runtimes disponíveis:
  - Claude Code no terminal;
  - Claude Code via ACP;
  - Codex via ACP;
  - Hermes via ACP.
- Claude ACP permite escolher modelos da família Claude.
- Codex ACP permite escolher modelos Codex/OpenAI compatíveis.
- Hermes permite usar providers configuráveis e modelos livres.
- A Central de API é integrada ao setup: o plano persiste apenas o
  `credentialId`; o segredo continua protegido no keychain.
- O backend resolve a credencial no momento do spawn, sem gravar a chave no
  canvas ou no plano.
- Cards de agente mostram runtime, provider e modelo escolhidos.
- Configurações de runtime sobrevivem ao reload e planos antigos recebem
  defaults compatíveis.
- Subagentes e conexões continuam sincronizados quando um papel é renomeado,
  movido ou removido.

## UI, estabilidade e qualidade

- Menu de conexão por arraste deixou de recriar componentes durante render.
- Efeitos de boot, Doctor, métricas e Sidebar foram ajustados para evitar
  renders em cascata.
- Contador de fluidez deixou de consultar o relógio durante render.
- Histórico interno de Novidades foi restaurado para as versões 0.1.142,
  0.1.143, 0.1.144 e 0.1.145.
- Gate de qualidade voltou ao baseline sem aumentar tolerâncias:
  ESLint 106, Clippy 86 e pendências de formatação reduzidas de 891 para 839.
